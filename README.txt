PRESIDENT OF TAIWAN: THE PEOPLE'S MANDATE
A classroom game. Works in any web browser. No accounts, no AI, no data collected.

To put it online, upload the file "index.html" (keep that exact name) to any web host.
Easiest options:
  1. GitHub Pages  (free)   2. Netlify (drag and drop the folder)   3. Cloudflare Pages (free)
  4. Your school's own website, if it can host an HTML file.

Everything the game saves stays on each student's own iPad (in Safari).
